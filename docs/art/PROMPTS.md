# CLLGE · Prompts para GPT Image 2 (cianotipia + un acento rojo)

## Cómo usarlos

1. **Pega el bloque STYLE al principio de cada prompt** y después el texto de la imagen.
2. Usa el **tamaño** indicado (si tu herramienta permite más resolución, mantén la misma proporción).
3. **Paneles que continúan** (marcados con 🔗): usa el modo *edición*, adjunta la imagen anterior y añade la frase CONTINUE.
4. Guarda cada imagen en **PNG con el nombre exacto** (`world-1.png`, `frame-3.png`…).
5. Mete todas en un **ZIP** y súbemelo al chat.

---

## STYLE (pégalo siempre primero)

```
Authentic cyanotype print on heavy cold-pressed cotton watercolor paper. Deep Prussian blue (#0B2A5B to #1E4F8C) with pale cream-white highlights (#F1EADB) where light was blocked; tonal range only in blues and cream. Soft halation around bright edges, fine paper-fibre texture, subtle uneven chemical mottling and a few tiny water spots. Exactly ONE small hand-painted accent in vermilion red (#FF3B2F, gouache, slightly outside the lines) on the element named below; nothing else is red. The image fills the whole frame edge to edge: no paper border, no brush-stroke edge, no frame. No text, letters, numbers, signatures, logos or watermarks. Calm, minimal, poetic composition with generous negative space; an original image, not imitating any existing photographer or artwork.
```

## CONTINUE (para los paneles 🔗, adjuntando la imagen anterior)

```
This is the next panel to the right of the attached image in one continuous panorama: the left 10% must continue exactly from the right 10% of the attached image (same horizon, hills, sky and water).
```

## PANORAMA (añádelo a los 4 paneles de la portada)

```
The horizon sits exactly 62% down from the top, perfectly level; low rolling hills on the far shore touch both side edges at the same height, so panels can be joined side by side.
```
